# 🎮 Halo: Combat Evolved — Gameplay Mod

## About the Project

A personal game modification project developed
using AI-assisted programming, Lua, Cheat Engine,
and Auto Assembly.

The project explores new gameplay mechanics,
character interactions, and creative enhancements
for Halo: Combat Evolved.

## 🚀 Features

- Custom character and ally spawning
- Companion AI behavior modifications
- Enhanced movement mechanics
- Flying and grappling mechanics
- Weapon modifications
- Energy swords
- Visual and lighting effects
- Vehicle control enhancements
- Sound effects
- Campaign gameplay improvements

## 🛠 Technologies

- Lua
- Cheat Engine
- Auto Assembly
- AI-Assisted Development
- Game Modding

## 🎯 Project Goals

- Explore game mechanics and creative design.
- Develop new gameplay experiences.
- Improve technical problem-solving skills.
- Explore AI-assisted game development.
